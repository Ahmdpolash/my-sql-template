# **Project Overview**

**Vlach Social** is a community-driven social networking and dating platform designed specifically for the Vlach community worldwide. The app will help users reconnect with their cultural roots, discover people from similar backgrounds, participate in local events, communicate with the community, and exchange goods/services through a marketplace.

The platform combines social networking, dating, events, classifieds, and community discussions into one ecosystem, allowing Vlach members to build meaningful connections based on heritage, location, and shared interests.

# **Core Features**

## **1\. User Registration & Onboarding**

* Email/social signup & login  
* User profile setup  
* Interactive heritage map selection  
  * Select ancestral village/region  
  * Select current location  
* Create cultural identity profile  
* Add:  
  * Profile photo  
  * Name  
  * Bio  
  * Interests  
  * Languages  
  * Location information

## **3\. Community Social Feed**

A dedicated dating experience for community members.

* Dating profile creation

* Like/pass actions  
* Mutual match notification

## **5\. Messaging System**

Communication between users.

Features:

* Marketplace conversations  
* Message notifications

Features:

  * Location

Example categories:

* Accommodation

* Travel sharing  
* Local businesses

## **8\. Community Forum**
